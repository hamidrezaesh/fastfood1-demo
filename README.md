# FastFood Website 🍔🍕🥗

This project is a **Fastfood website** built with **React**, including pages for Home, Order, About, Contact, and Cart.  
It features a responsive design that works smoothly on both desktop and mobile devices.

---

## ⚡ Features
- Display food menu with images, names, and prices
- Simple cart with increase/decrease item quantity
- Login and Register forms with clean design
- Responsive Navbar and Footer
- Interactive buttons with hover effects
- Mobile-friendly design with hamburger menu

## 🛠️ Technologies

- React
- React Router
- CSS
- [Heroicons](https://github.com/tailwindlabs/heroicons) for icons
